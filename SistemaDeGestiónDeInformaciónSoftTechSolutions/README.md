# Sistema de Gestión de Información Softtech

## Descripción

Sistema de gestión de información desarrollado como proyecto formativo para apoyar la administración, organización y consulta de la información de una organización.

El proyecto busca proporcionar una solución tecnológica que permita gestionar la información de manera organizada, facilitar las operaciones de registro y consulta y mejorar el control de los datos.

## Objetivo

Desarrollar un sistema de información que permita gestionar de manera eficiente los datos relacionados con los procesos de la organización, aplicando buenas prácticas de desarrollo de software y diseño de bases de datos.

## Funcionalidades

- Registro de información.
- Consulta de información.
- Actualización de registros.
- Eliminación de registros.
- Gestión y almacenamiento de información.
- Organización de los datos mediante una base de datos.
- Administración de la información de acuerdo con los requerimientos del proyecto.

## Base de datos

El proyecto cuenta con una base de datos estructurada para almacenar y relacionar la información necesaria para el funcionamiento del sistema.

La base de datos está compuesta por diferentes tablas relacionadas entre sí mediante claves primarias y foráneas, permitiendo mantener la integridad y organización de la información.

## Tecnologías

- HTML
- CSS
- JavaScript
- Node.js
- MySQL
- Git
- GitHub

## Estructura del proyecto

La estructura del proyecto se organiza de acuerdo con los componentes necesarios para el desarrollo del sistema, incluyendo los archivos correspondientes a la aplicación y a la base de datos.

## Control de versiones

El proyecto utiliza Git para el control de versiones y GitHub como repositorio remoto para almacenar y gestionar el código fuente.
